# 거래시간·종목 예외 점검

## 거래시간

`market_sessions`는 Toss 공식 `/api/v1/market-calendar/KR`의 당일 통합(KRX+NXT) 세션을 저장한다. 당일 검증된 캐시를 사용하며 30분마다 갱신한다. API 실패 시 당일 정상 캐시는 유지한다. 인증이 설정된 운영 환경에서 당일 일정을 확인할 수 없으면 매수·매도 판단을 보류한다. 오래된 캐시를 당일 검증으로 취급하지 않는다.

- 정규장 매매 허용과 장전 조회 범위를 응답 세션에 맞춘다. 장전 예정 시각은 정규장 시작30분 전이며 시세 수집은 프리마켓 연속매매 구간을 넘지 않는다. 프리마켓이 없으면 시작30~10분 전의 참고가격 조회를 사용한다.
- 기존 intraday 작업이 변경 개장일의 장전 조회를 보충한다. 당일 이미 시도한 장전 배치를 반복 실행하지 않는다.
- 반복 예약 구간은18시까지 확보하되 실제 작업은 공식 정규장 종료10분 후까지만 실행한다. 일반 거래일의 매매 시간은 늘리지 않는다.
- 16시 daily 작업은 필요 시 공식 종료30분 후까지 기다린다. 이 대기는 전역 매매 뮤텍스를 획득하기 전에 수행하므로 진행 중인 매매 점검을 막지 않는다.
- 장전 표시용 평가를 정규장 위험관리 기준으로 기록하지 않는다.

## 거래정지·기업행동

`stock_events`는 보유 및 최근 추천 종목의 공식 기본정보를 조회한다. 매수 직전과 매도 점검에서도5분 캐시를 확인한다. 상태 확인 실패, KRX 거래정지/미확인, 비활성 상장 상태는 해당 종목의 가상 매매를 보류한다. NXT만 정지된 것을 KRX 전략 전체 정지로 해석하지 않는다.

전일부터 보유한 종목은 직전 공식 거래일의 수정/비수정 일봉 종가를 비교한다. 동일 날짜의 종가 차이가0.5%를 넘으면 가격 기준 변경으로 검토를 요구한다. 종목 식별번호 변경도 검토 대상으로 남긴다. 이는 분할·권리락 등의 **의심 감지**이며 특정 기업행동의 확정이나 조정 비율 산출이 아니다. 일반적인 주가 하락을 매수가와 비교해 기업행동으로 오인하지 않는다.

검토 사유와 최초 근거는 `data/stock_events.db`에 유지된다. 이후 조회가 정상이어도 자동 해제하지 않는다. 가격·원가·보유 수량·현금·과거 매매 원장은 자동 수정하지 않는다.

최근90일 최대100건의 DART 공시 제목 중 분할·병합·감자·합병·권리락·배당락·거래정지 관련 제목을 참고로 표시한다. 장전과 마감 처리에서 갱신하며, 제목만으로 효력일을 확정하거나 매매를 보류하지 않는다. 미연결/조회 실패는 별도 표시한다. 전체 기업행동의 완전한 탐지나 배당금·신주·단주 처리를 보장하지 않는다.

운영자가 실제 권리 내용과 원가·수량 등을 별도로 확인한 뒤에만 아래 확인 처리를 사용한다. 실행 시 현재 `review_fingerprint`와 비어 있지 않은 확인 내용이 필요하며 지문이 바뀌면 거절한다. 확인 처리는 회계 원장 보정 기능이 아니다. 거래정지 자체는 이 확인으로 해제되지 않는다.

```text
python -m stock_alarm.stock_events --ack <종목코드> --fingerprint <현재검토지문> --note "별도 확인한 내용"
```

V1·V2 계좌에 공식 세션, 매매 보류 사유, 기업행동 참고 경고가 표시된다. 신규 API는 기본정보와 시세의 읽기 전용 경로만 사용한다.

공식 명세: https://developers.tossinvest.com/docs/market-data 및 https://openapi.tossinvest.com/openapi-docs/latest/openapi.json (`KrMarketDay`, `StockInfo`, `KrMarketDetail`, `candles.adjusted`).
