# 하락장 대체 계좌·회복 기회비용

실행: `python -m stock_alarm.bear_account_research`.
저장된 원장·과거 가격·추천 기록만 읽으며 네트워크 조회와 운영 주문은 없다.
현재일 장중 봉을 제외하기 위해 직전 날짜까지의 마지막 저장 KOSPI 거래일을 종료일로 정한다.

## 계좌 재현

입금·매수·부분/최종 매도와 일별 종가를 시간 순으로 재생한다.
수수료·보유 한도 없는 별도 감사 재생의 현금과 잔여 주식 수를 원장과 대조한다.
실험 네 계좌에는 모두 동일한 최대 7종목 한도를 적용하며, 감사 재생을 실험 대조군으로 쓰지 않는다.
비용 실험은 매수·매도 각 0.15%, 현금 부족 시 정수 수량 축소, 차입 없음이다.
입금 시 입금 전 자산으로 단위당 NAV를 구해 단위수를 늘린다.
일별 단위 NAV로 입금 영향을 제외한 TWR과 최대낙폭을 계산한다.
보유 중 장중 입금이 있는데 입금 직전 평가가 없으면 임의 계산하지 않고 중단한다.

하락장은 직전 저장 거래일 종가와 MA20이 모두 MA60 아래인 경우다.
비교군은 기존 매수 기회, 하락장 수량 절반, 하락장 매수 보류다.
부분 매도는 원래 누적 매도 수량에 비례해 내림하며 최종 매도에서 남은 물량을 종료한다.
평가일 종가가 없는 보유 종목은 전일 값으로 채우지 않고 오류로 처리한다.
전체 매수 엔진을 재실행하거나 다른 미매수 종목을 대신 고르지 않는다.

## 회복 후 20거래일 고정 벤치마크

회복일 종가로 상태를 확인한 뒤 20거래일을 관찰한다.
실행이 완료된 적극투자형 추천 중 공통 필터 통과·선택 기록을 사용한다.
신호 확인 시각은 후보 평가·실행 완료·회복일 종가 시각 중 가장 늦은 시각이다.
다음 거래일 시가보다 뒤의 신호는 사용할 수 없다. 실패 실행의 잔존 추천은 제외한다.

회복일 보류 계좌 현금에서 기존 계좌 현금을 뺀 양수 금액만 별도 예산으로 묶는다.
종목당 예산 1/7, 계좌 전체 최대 7종목, 추가 물량의 같은 종목 중복 진입 없음이다.
기존·축소·보류·재진입 계좌 모두 원래 매수와 추가 진입에 7종목 한도를 적용하고 제한 건수를 표시한다.
다시 하락장이면 신규 진입을 중단하며 추가 물량은 예정된 20번째 거래일 종가에 청산한다.
따라서 추가 물량 자체 손익과 보류 계좌 대비 자산 차이는 같지 않을 수 있다.
보류와 재진입의 차이는 같은 한도에서 재진입 정책을 추가한 영향이다.
최초 한도가 달랐던 v1 결과는 실행별 원본으로 보존하고, 현재 표는 v2 공통 한도 결과를 사용한다.

## 산출물과 한계

`reports/bear_account_research/runs/`에 입력·해시·결과·일별 CSV·보고서를 실행별로 보존한다.
계산이 성공한 뒤 최상위 파일을 교체하며 실패한 재실행은 직전 정상 결과를 덮어쓰지 않는다.
대시보드 v1·v2는 최상위 결과의 요약표만 읽고 조회 때 재계산하지 않는다.

과거 일봉 가격의 당시 버전, 시가·종가 체결 가능성, 슬리피지·배당·기업행동 조정은 보장하지 않는다.
일별 최대낙폭은 장중 최대낙폭이 아니다. 회복 재진입은 운영 매도 규칙을 적용한 전략이 아니라
정해진 기간 보유하는 기회비용 벤치마크다. 신규 전향 실험과 운영 규칙은 변경하지 않는다.
