# 목표 도달 기록과 하락장 비교

2026-10-29에 기존 48건의 동결 입력으로 추가 탐색을 수행했다.
실행: `python -m stock_alarm.target_bear_research`
입력 스냅샷이 없으면 먼저 `python -m reports.run_current_data_experiment`로 로컬 DB의 비교 가능한 거래를 동결한다.
입력: `reports/current_data_experiment/input_snapshot.json`, 저장 KOSPI 일별 종가.
출력: `reports/target_bear_research/REPORT.md`, `results.json`, `index_snapshot.json`.
v1 연구 탭과 v2 연구·상태 화면은 저장된 보고서를 읽으며 조회 때 재계산하지 않는다.

## 목표 기록

실제 매도 단계와 매도 사유에서 확인한 익절 기준을 보존한다.
과거 모든 시점의 목표 설정은 확인되지 않아 +10%·+20% 고정 진단과 실제 체결 여부를 구분한다.
가격 미관측을 장중 목표 미도달로 단정하지 않는다.

신규 매수 관측의 `entry_take_profit_policy`는 진입 시점의 목표 비율과 분할 비율을 저장한다.
진입 기록의 익절 허용 여부는 참고 설정이며 실제 시장 국면별 허용 여부는 매도 평가 때 결정한다.
매도 평가의 `position_checks`에 `take_profit_1_pct`, `take_profit_2_pct`,
`take_profit_1_sell_ratio`, `take_profit_allowed`를 함께 저장한다.
기존 행은 NULL로 유지한다. 목표 가격은 당시 `entry_price * (1 + pct/100)`로 재현한다.
매도 판단은 같은 해석 함수를 재사용하며 기존 조건·우선순위·기본값을 유지한다.

## 하락장 비교

매수일이 저장 거래일에 있고 직전 거래일에 60개 종가가 있을 때만 판정한다.
직전 종가와 MA20이 모두 MA60 아래이면 하락장이다. 매수일 종가를 판정에 넣지 않는다.
동일 완료 거래에서 기존, 정수 수량 절반, 매수 보류, 기존 +5% 절반 익절 추가를 독립 비교한다.
축소 후 부분 매도는 원래 누적 매도 수량에 비례해 내림하며 잔량은 원래 최종 매도에서 종료한다.
익절 조건을 바꾼 계좌 전체를 재실행한 결과가 아니라 원래 매도 기록에 배분한 기계적 비교다.
분모는 원래 배정자금, 남긴 자금은 무이자 현금, 재투자는 없다. 비용은 매수·매도 각 0.15%다.

거래별 비교는 완료했다. 계좌 최대낙폭·일별 현금 비중·회복 후 20거래일 신규 추천 기회비용은
`stock_alarm.bear_account_research`의 원장 고정 계좌 재현과 회복 재진입 벤치마크로 별도 계산했다.
결과는 `reports/bear_account_research/REPORT.md`와 v1·v2의 하락장 대체 계좌 표에서 확인한다.
전체 매수 엔진의 후보·순위·배분을 다시 실행하는 전략 백테스트와는 구분한다.
회복 후 20개 저장 거래일 확보 여부만 지수 구간 진단으로 저장하며 전략 성과로 표시하지 않는다.
이 결과로 운영 규칙을 바꾸거나 전향 연구 시작일을 소급하지 않는다.
