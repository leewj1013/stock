# 매도 재분석 관찰 v1

2026-10-19 구현. 기존 매도 신호·주문은 유지하고 국내 적극투자형의
position_checks를 별도 data/sell_research.db에 기록한다. 미국 동결 엔진은 수정하지 않는다.
수집 시작은 DB 최초 초기화 시각이며 과거 판단을 전향 실험으로 소급하지 않는다.

## 순서와 기준

1. 위험 한도: 첫 관찰 ATR의 2배, 최소 5%·최대 10%로 고정한다.
   이는 검증용 가정이며 최적값이 아니다. 진입 당시 위험 한도라는 의미가 아니다.
   종목 경고 또는 한도 이탈은 보유 연장보다 우선한다.
2. 재분석: 손절·추세·시간·익절·수익 반납을 개별 분류하고 원본 판단을 저장한다.
   최초 매수 근거, 시장 대비 강도는 기존 스냅샷에 없어 확인 불가로 기록한다.
   기준일이 판단일보다 오래되거나 가격이 없으면 데이터 확인 필요로 분류한다.
3. 기한부 보유: 추세/시간 조건만 있고 20일선과의 거리가 ATR 0.5배 이내면
   1거래일만 연장한다. 매도는 두 번째 거래일 시가, 추가 연장 없음.
4. 익절: 익절 조건이면 50%를 다음 거래일 시가에 팔고 나머지는 종가 고점의
   max(4%, 첫 매도 판단 ATR 2배) 하락 또는 고정 위험선 이탈 다음 거래일 시가에 판다.

## 성과 해석

같은 진입 건은 최초 신호 한 건만 비교한다. 기준 시점은 판단 다음 거래일 시가다.
비교 기준은 전량 신호 100%, 부분 신호 50%를 해당 시가에 매도한 표준 가정이다.
기존 HOLD에 위험 한도만 먼저 도달하면 기준은 계속 보유한다.
잔여 수량은 각 관찰기간 종가로 평가하고 매도대금은 현금으로 유지한다.
실제 계좌의 후속 주문을 복제하지 않으며 소수 수량을 허용한 독립 포지션 비교다.
따라서 실제 체결·정수 수량·재투자·포트폴리오 최대낙폭 결과로 해석하면 안 된다.

1·3·5·10거래일별 비용 반영 수익률 차이, 기초종목의 최대 상승/하락폭,
잔여 수량 비율을 저장한다. 매도비용 30bp, 별도 호가 슬리피지는 미반영이다.
당일 미완성 봉은 사용하지 않아 결과 반영은 보수적으로 하루 지연한다.
미완료 기간은 null 대신 해당 결과 자체가 없으며 0%로 채우지 않는다.
데이터 오류는 episodes.error에 남고 배치 실패로 보고한다.
고정된 규칙 변경은 새 버전 DB로 분리해야 한다.

## 운영

마감 sell_performance와 DB 유지보수 작업에서 자동 수집한다.
수동 실행: python -m stock_alarm.sell_research
대시보드 국내 전략 연구 탭에서 최근 사례와 완료/오류 수를 확인한다.
관찰 DB는 data 디렉터리의 로컬 데이터이며 Git에 포함하지 않는다.

11월 중순에는 완료된 독립 사례만 중간 평가한다. 사례 수·시장 국면이 부족하면
규칙 채택을 미루며, 진입 근거/시장 상대강도, 위험중립형 및 미국의 별도 관찰,
실제 수량을 반영한 계좌 재생은 후속 확장이다.
