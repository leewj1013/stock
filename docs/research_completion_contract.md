# 관찰 연구 방향과 완료 기준

## 작업 범위

철회 표본의 별도 탐색은 사용자 요청으로 보류한다. 현재 작업은 국내 적극형의 신규 가상매수 연구,
동시호가 전 호가 청산 관찰, 기존 전략과의 같은 거래 비교다. 실제 계좌의 주문 체결 연구로 표현하지 않는다.
과거 48건 탐색 결과는 신규 전진 연구의 표본·성과와 합치지 않는다.

## 단계별 완료 기준

| 단계 | 완료 기준 | 표본이 없을 때 |
|---|---|---|
| 구현·배포 검증 | 규칙 고정, 원자료 보존, 시점·비용·잔량 검사, 자동 실행 연결, 회귀 테스트 및 실행 사본 확인 | 구현 완료 상태로 유지 |
| 실제 전 구간 검증 | 등록 후 적격 신호 1건 이상에서 진입·청산 호가·거래시간·비용·근거를 모두 재현 | 실제 사례 대기 |
| 전략 효과 검증 | 같은 완료 거래에서 대조군과 비교하고 표본 수·기간·조건 발생 수·자료 제외를 함께 평가 | 결론 없음 |

실제 사례 1건은 수집·계산 경로의 점검이며 전략의 유효성 증명이 아니다.
일정 개수만 채웠다는 이유로 전략을 자동 승격하지 않는다. 표본이 0건인 동안 구현을 반복 변경하지 않는다.

## 이미 고정한 규칙

- 기존 익절·0/-3/-5% 독립 실험은 각 DB의 버전·등록 시각·규칙을 유지한다.
- 대체 청산은 `day-quote-exit-v1`, 신호는 `kr-opening-range-v2`만 받는다.
- 진입 판단은 신호 최초 확인과 트리거 봉 종료 중 늦은 시각이다. 이후 60초 내 유효 매도호가를 사용한다.
- 청산 판단은 15:10 이상 15:19 미만 첫 유효 호가다. 이후 60초 내 다음 유효 매수호가를 사용한다.
- 수량 1주, 매수·매도 비용 각 15bp, 공식 연속매매 구간과 잔량 조건을 검사한다.
- 첫 청산 판단을 놓치면 유리한 나중 시점을 다시 고르지 않는다. 15:20 이후 가격으로 대체하지 않는다.
- 규칙·비용·원 신호 버전이 바뀌면 새 연구 버전을 등록한다. 기존 시작 시각을 다시 잡거나 결과를 덮어쓰지 않는다.

## 단일 사례와 근거

대체 청산 사례의 키는 `(연구 버전, 종목, 신호일)`이다.
`research_extensions_v1.db.quote_exit_cases`에 최초 신호 입력을 등록한다. 같은 키의 입력은 다시 등록하지 않는다.
완료 또는 자료 부족으로 제외한 결과는 고정하며, 신호·호가·거래시간 근거와 SHA-256을 함께 보존한다.
이후 원자료가 바뀌어도 기존 완료 결과를 조용히 다시 계산하지 않는다.
계산 오류나 원자료 정정이 확인되면 기존 근거를 보존하고 별도 감사·새 버전으로 재검토한다.

아직 진행 중인 사례만 새 관측으로 갱신한다. 실제 평가 시각보다 뒤의 신호·호가는 사용하지 않는다.
저장된 평가 시각보다 과거 시각으로 결과를 갱신하는 요청은 거부한다.
사례 DB 갱신은 트랜잭션으로, 화면용 JSON은 임시 파일 교체로 처리한다.

## 상태와 분모

| 상태 | 의미 | 성과 분모 |
|---|---|---|
| 신규 적격 신호 없음 | 아직 등록할 대상 없음 | 제외 |
| WAITING_ENTRY_QUOTE | 진입 판단 후 허용 관측 시간 진행 중 | 제외 |
| WAITING_EXIT_WINDOW | 진입 자료 확보, 청산 판단 시간 전 | 제외 |
| WAITING_EXIT_QUOTE | 청산 시간대의 후속 호가 관찰 중 | 제외 |
| ENTRY_DATA_MISSING | 허용 진입 시간이 지났지만 적격 호가 없음 | 제외 사유·건수 표시 |
| EXIT_DATA_MISSING | 청산 시간대가 지났지만 적격 호가 쌍 없음 | 제외 사유·건수 표시 |
| SCENARIO_COMPLETE | 진입·청산·비용을 확인한 관찰 시나리오 | 완료 표본에만 포함 |

자료 부족을 수익률 0%로 넣거나 관측을 놓친 사례를 계속 대기 중으로 표시하지 않는다.
조건이 발생하지 않은 정상 완료 거래와 자료가 없는 거래를 구분한다.
기존 익절·손절 비교는 동일한 종료 거래를 대조군으로 쓰며 1차 익절 대상 분모도 따로 표시한다.
계좌 복리 수익률·최대낙폭을 거래별 평균 차이로 대신하지 않는다.

## 다음 수정이 필요한 경우

새 적격 표본이 생기면 자동 작업의 등록·진입·청산·계산 결과를 점검한다.
자료 제외가 발생하면 보존된 근거로 수집 누락, 시각·잔량 부적격, 거래시간 미확인을 구분한다.
원인 확인 없이 임계값·시작일·체결 가정을 바꾸지 않는다.
프로세스 오류, 원자료 정정, 프로토콜 변경 요청이 없고 표본만 부족하면 추가 구현 대신 관찰을 유지한다.

과거 업종·공매도 자료는 당시 공개 버전·시점이 확인되지 않은 구간의 사용 제한을 유지한다.
철회 표본 보류는 다른 익절·손절·호가 관찰의 완료 조건으로 사용하지 않는다.
