# 매수 의견 관찰 v1

국내 적극투자형의 새 추천을 대상으로 한다. 기존 추천/매수/매도와 미국 동결
엔진은 바꾸지 않는다. data/entry_research.db 최초 생성 시각 이후 기록만 수집한다.
원본 candidate_snapshots의 최초 추천 시점 지표와 전략 버전을 저장하고,
같은 종목·같은 날 재추천은 최초 기록을 유지한다. 다른 날 추천은 별도 사례이나
관찰기간이 겹칠 수 있으므로 독립 표본 또는 합산 포트폴리오로 해석하지 않는다.

## 사전 고정 가설

- 기준: 다음 거래일 시가에 계좌 10% 비중을 가상 투자.
- 가격 부담안: 20일선 위 거리 >= 추천 시점 ATR 2배이면 투자하지 않고 현금 유지.
- 위험 비중안: 손절폭 = min(10%, max(5%, ATR 2배)), 투자 비중은
  min(10%, 계좌 위험 예산 0.5% / 손절폭). 갭 하락 손실을 보장하는 한도는 아니다.
- 유형: 20일선 위 + 거래량 배율 >=2는 추세·거래량, 그 외 위는 추세,
  아래는 20일선 아래로 분류한다. 이는 관측 가설이지 실제 추천 이유의 복원이 아니다.
- 예상 관찰기간: 10거래일. 가격과 ATR 또는 당일 기준일이 없으면 자료 부족 처리.

## 공통 매도와 측정

세 안의 매도 기준은 같으며 진입가 기준 고정 위험선을 종가로 이탈하면 다음
거래일 시가에 매도한다. 이후 현금 유지. 1·3·5·10거래일에 청산가치를 평가한다.
종가 청산가치는 비교용 평가이며 실제 종가 주문 체결을 주장하지 않는다.
매수와 매도 비용 각 15bp, 소수 수량 가정. 별도 슬리피지·세금 시장별 차이와
정수 수량·복수 종목 자금경합은 아직 모델링하지 않는다.

주식 순수익률, 각 비중의 계좌 기여도, 기준 대비 차이, 첫날 움직임,
기초종목 MFE/MAE, 고점 반납폭, 모의 손절 이후 회복률을 기록한다.
첫날 하락은 진입 문제 후보, 수익 반납은 보호 규칙 후보, 손절 후 회복은
손절 민감도 후보로 해석하되 인과관계로 확정하지 않는다.
아직 손절하지 않은 사례의 매도 후 회복률은 null이다.

현재 날짜의 봉은 제외하며 미완료 기간은 0으로 채우지 않는다.
기존 매도 관찰과 함께 마감 성과/DB 유지보수 배치에서 갱신하며 백업한다.
국내 전략 연구 탭에 최근 20건과 전체 완료/자료 부족/오류 수를 보여준다.
규칙을 바꾸려면 새 버전의 DB를 사용한다.

수동 실행: python -m stock_alarm.entry_research

실제 매수와 연결한 투자 근거, 시장/업종 상대강도에 따른 보유 연장,
위험중립형·미국 계좌 확장은 별도 후속 검증이다.
