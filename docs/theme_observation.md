# 테마주 관찰 v1

실제 추천·매수·매도는 변경하지 않는다. 네이버 증권의 당일 테마 순위 100개를 마감 후
날짜별로 고정 저장하고, 관찰 DB 생성 이후 새로 조건을 충족한 테마만 전진 관찰한다.

## 시작 조건

- 구성종목 3개 이상
- 상승 종목 비율 50% 이상
- 테마 당일 등락률 +2% 이상
- 테마 거래대금 50억원 이상

## 세 가지 비교

1. 거래대금 1위 대장주와 테마 전체 일간 등락률 합성 결과
2. 최초 포착 다음 거래일 시가 진입과 다음 마감에도 시작 조건을 유지한 뒤 그 다음
   거래일 시가에 진입
3. 현재 손절·20일선·수익반납·기간·분할익절 규칙과, 테마 상승 종목 비율 35% 미만
   또는 테마 하락이 2회 연속이면 다음 거래일 시가에 잔여분 절반을 한 번 축소하는 규칙

매수·매도 비용은 각각 15bp이며 1·3·5·10·20거래일을 측정한다. 테마 전체 수익은
공급자의 일별 테마 등락률을 합성하므로 직접 매수 가능한 동일가중 포트폴리오 수익과
같지 않다. 공급자 테마 구성과 분류는 바뀔 수 있으므로 실제 주문에는 사용하지 않는다.
