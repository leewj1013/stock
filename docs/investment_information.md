# 국내 투자 정보 화면

V1·V2가 같은 저장 자료와 계산 모듈을 사용한다. 첫 화면에는 계좌 변화·확인 사항·예정 일정만 펼치고, 추가 분석은 접어 둔다. 가상계좌와 관찰 자료만 다루며 주문 규칙·실계좌 주문은 변경하지 않는다.

## 일정 수집과 한계

`stock_alarm.investment_calendar`가 두 국내 가상계좌의 보유종목을 모아 `data/investment_calendar.db`에 저장한다. 장 시작 작업의 기존 핵심 단계 이후와 장 마감 작업에서 실행한다. 성공 결과는 6시간 동안 재조회하지 않으며 조회 실패는 이전 자료를 보존한다. 기본 수집 예산은 60초이고 진행 중 네트워크 요청은 기존 타임아웃까지 기다릴 수 있다. 목록 상한·시간 제한·원문 실패는 화면에 표시한다.

실적 공시 예고와 지원되는 기업설명회 원문 양식에서 읽은 날짜만 예정일로 사용한다. IR 개최일을 실적 공시일로 치환하지 않는다. 정정·취소·철회 표시가 있으면 자동 확정하지 않고 원문 확인 대상으로 분리한다. 같은 접수번호의 철회 표시 변경도 다음 수집에서 감지한다. 배당락·증자·분할·합병·거래정지는 공시 제목만으로 효력일을 추정하지 않는다. 공시일과 효력일은 별개이며 공시 목록에 없다고 일정이 없다고 단정하지 않는다.

## 계산 범위

계좌 대사는 현재 저장 시세 기준이다. 가격 시점이 서로 다를 수 있어 각 종목 기준 시각을 제공한다. 직접 가격 수집·DB 초기화·원장 변경을 화면 조회에 추가하지 않는다. 고빈도 종목 점검 이력은 종목·시점 인덱스로 필요한 기록만 읽는다. 시계열 캐시 디렉터리는 종목마다 재검색하지 않고 짧은 시간 동안 목록을 공유한다.

연구의 하락장은 진입 직전 완료 KOSPI 종가와 MA20이 모두 MA60 아래인 경우다. 다른 장세는 상승·횡보를 포함한다. 종목·기간이 겹치는 표본은 독립 표본이 아니며 표본 수만으로 통계적 유의성이나 실전 채택을 주장하지 않는다. 기존 과거 탐색 결과의 조건·비용·한계는 기존 연구 상세에 유지한다.
