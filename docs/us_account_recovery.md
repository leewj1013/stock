# 미국 계좌 갱신 및 복구

- 전략 재현은 기존 고정 엔진과7개 파일 해시가 모두 일치하는 소스 아카이브를 사용한다. 국내 운영 코드 수정으로 미국 엔진을 교체하지 않는다. 환경 설정·가중치가 고정값과 달라지거나 아카이브 검증이 실패하면 갱신을 보류한다.
- 사전 검사나 SPY 수집 등 조기 실패도 상태 파일에 반영한다. 기존 정상 상태를 그대로 유지하지 않는다.
- 확정일까지는 해당 날짜의 입력 ZIP을 사용하고 이후에만 새 수집 봉을 붙인다. 확정 입력·주문·일별 상태가 재현되지 않으면 이전 계좌 기록을 덮어쓰지 않는다. 접합 지점의 종가가0.5%를 초과해 달라진 경우 가격 기준 변경을 별도 검토한다.
- 고정 설정 이행은 `migrate_legacy_engine()`이 원래 엔진·설정의 일치와 확정 상태 재현을 확인한 후 백업을 만들고 실행한다. 해시만 임의로 덮어쓰지 않는다. 실제 가격 기준이나 전략이 달라진 경우 이행을 거절한다.
- 최초 신호일 또는 마지막 확정일 이후 기준 SPY 세션에 필요한 종목 봉이 누락되면 당일 확정을 보류한다. 거래정지·상장 기간 예외를 수집 누락과 구분할 근거가 없으면 자동 면제하지 않는다.
- 미국 현지 시각16:15 이전에는 당일 봉을 완성 봉으로 취급하지 않는다. 기존 한국 시각06:45/07:45 실행은 서머타임 여부와 관계없이 이 버퍼 이후다. 요청 종료일은 완료 가능 날짜 다음 날로 계산하며 연도에 고정하지 않는다. 휴장일은 원자료에 봉이 없어 자연히 제외된다. 수동 장중/조기 폐장 당일 실행에는 보수적으로 자료가 늦게 반영될 수 있다.
- SPY 기준 장부는 유효한 날짜·양의 유한 가격을 확인한 뒤 임시 파일을 완성하고 교체한다. 쓰기·교체 오류 시 이전 장부를 유지한다.
- 진입 연구 v2는 직전 완료 세션의 SPY/VIX로 위험 비중을 정한다. 기존 `data/us_research.db`는 보존하고 새 `data/us_research_entry_v2.db`를 사용한다. 연구 오류나 SEC 자료 부족은 전략 계좌 원장을 바꾸지 않는다.

설정 이행과 지연 거래일 재현은 가상 계좌 기록의 복구이며 실계좌 주문을 제출하지 않는다. 확정된 과거 원장과 입력 보관본은 그대로 유지한다.
