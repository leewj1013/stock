# 비매매 연구 신뢰도 점검 사전 범위 — 2026-10-22

순서: 독립 표본 → 연구 유효기간 → 출처 일치성. 초기 스키마·행 수·예시 확인 후 이 문서를 작성했으며, 새로운 수익 전략의 유의성 검정이 아니다. 운영 DB는 읽기 전용으로 열고, 네트워크·주문·알림·학습 설정 변경 없이 저장된 자료만 분석한다.

1. 독립 표본: 현재 학습과 같은 `quality_status=valid`, 20일 성과 완료, 유효 objective 표본(최대 최근 1,000개). 원본 CSV와 DB의 중복·추천일·진입일·종목 집중을 구분한다. 날짜별 건수의 Kish 등가 균등일 수는 집중도 지표이며 실제 독립 표본 수가 아니다. KOSPI 캐시의 거래일을 이용한 10/20거래일 구간 중첩과 비중첩 구간 수는 대리 진단이며 종목별 거래정지까지 반영한 정확한 청산일이 아니다.
2. 같은 평균 목표의 불확실성: 행 독립 가정의 표준오차와 진입일 묶음의 이동블록 부트스트랩(10·20거래일, 각 2,000회, seed=20261022)을 비교한다. 추천 없는 거래일도 보존하고 블록별 합계·건수를 함께 재표집해 행 가중 평균을 유지한다. 95% 백분위 구간은 짧은 기간의 탐색적 민감도이며 매매 성과·확정적인 유효 표본 수로 해석하지 않는다. 기존 학습 3개 구간의 경계 날짜와 목표기간 겹침도 확인한다.
3. 연구 유효기간: 기존 완료 연구의 보고서·실행 소스 해시, 최초 연구일과 최신 수정일, 공정 종목군의 파일별 마지막 날짜를 기록한다. 최신 수정일 이후에 신호와 목표가 모두 발생한 동결 정의의 비교 자료만 전진 검증으로 인정한다. 오래된 자료의 기간 분리는 전진 검증으로 세지 않는다. 월별 연구 최소 12개 월, 주별 최소 26개 주, 포트폴리오 비교 최소 252거래일을 쌓기 전에는 유효/소멸을 판정하지 않는다. 기간 충족 후에도 기존 정의·비용·검정 집단을 고정하고 q<0.05 및 비용 차감 효과 방향을 확인한다.
4. 출처 일치성: `price_quality` 전체 행의 날짜·출처·비교값 유무·상태를 확인하고, 같은 관측일·종목·출처·참조출처·시간대에서 마지막 행만 남긴 별도 집계도 제공한다. 가격 차이 절대값의 중앙값·95백분위·0.5% 초과율을 계산하되 이를 공급자 오류율로 부르지 않는다. 두 공급자의 실제 시세시각·세션·수정주가 기준이 없거나 참조출처 표기가 모호하면 미확인으로 분류한다. 09:00~15:30 장중, 15:30~16:00 장후 초기, 16:00 이후, 기타 시간대를 섞지 않는다.
5. 후속 수집 계약: 출처별 실제 공급자, 요청·응답시각, 시세시각, 시장·세션·통화·가격 단위·수정주가 여부가 있어야 정확한 출처 비교를 진행한다. 기존 장부의 빈 값을 추정으로 채우지 않는다. 거래량·재무값 비교는 현재 가격 로그에 없으므로 검증 불가로 명시한다.
